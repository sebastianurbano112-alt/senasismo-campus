# SeñaSismo Campus

Proyecto académico de HCI for UX Design orientado a explorar una comunicación sísmica más accesible en un campus universitario.

## Sitio publicado

https://sebastianurbano112-alt.github.io/senasismo-campus/

## Alcance

La página ofrece contenidos de preparación, una alerta de simulacro, orientación textual, preferencias visuales y una solicitud de práctica guardada en el navegador. El laboratorio permite ensayar asignación, acuse, derivación y revisión de contenido ficticios.

**Este proyecto es una demostración. No recibe ni emite alertas oficiales, no comunica solicitudes a brigadistas, no sustituye los protocolos de emergencia y no debe utilizarse para emergencias reales.** No dispone de autenticación institucional, un servicio compartido, un directorio oficial ni recursos LSP validados.

## Archivos

- index.html: estructura, secciones y formulario.
- style.css: presentación, foco visible y adaptación responsive.
- app.js: validación, mensajes, preferencias y simulaciones locales.

## Ejecución local

Descarga los archivos y abre index.html en un navegador moderno o sirve el directorio con un servidor estático. No se requieren dependencias de instalación ni compilación.

## Publicación

GitHub Pages publica el contenido de la raíz de la rama main. Al confirmar cambios en esa rama se ejecuta el flujo de despliegue de Pages. Verifica su resultado en la pestaña Actions antes de probar el sitio.

## Accesibilidad y estado

Se han incorporado idioma español, etiquetas de campos, enlace para saltar al contenido, foco visible y mensajes textuales. Las pruebas efectuadas hasta ahora son parciales; no se declara conformidad integral con WCAG. Las 30 historias core del informe no están completamente implementadas ni validadas.

## Privacidad

Las solicitudes y preferencias de práctica se guardan localmente cuando el navegador lo permite. No se debe introducir información personal o sensible. El botón de eliminación borra la solicitud de prueba local.
